# 💌 Untuk Nasythaa

> Sebuah surat cinta kecil yang dibuat khusus untuk **Nasythaa**.

Website ini adalah pengalaman surat cinta interaktif dengan tema **Starry Night**.
Setiap scene berisi pesan yang berbeda dan dapat dibuka secara bertahap melalui interaksi sederhana.

## ✨ Features

* 🌌 Tema **Starry Night**
* 💌 Surat cinta interaktif
* ✨ Animasi bintang dan sparkle
* 💫 Transisi antar-scene
* 💌 Animasi membuka amplop
* 📱 Responsive untuk HP, tablet, dan desktop
* 🌙 Mendukung `prefers-reduced-motion`
* ⚡ Tanpa framework atau build tool
* 🚀 Siap digunakan di GitHub Pages

## 📁 Struktur Project

```text
nasythaa-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

### File Utama

**`index.html`**
Berisi struktur website dan seluruh isi surat. Terdiri dari **5 scene**:

* Opening
* Surat 1
* Surat 2
* Surat 3
* Ending

**`css/style.css`**
Mengatur tampilan website, termasuk warna, typography, layout, responsive design, dan animasi.

**`js/script.js`**
Mengatur interaksi website seperti particle bintang, pembukaan amplop, perpindahan scene, dan efek sparkle.

## 🌠 Teknologi

Website ini dibuat menggunakan:

* HTML5
* CSS3
* JavaScript

Tidak menggunakan:

* Backend
* Database
* Build tool
* Framework
* Dependency eksternal

Website dapat langsung dijalankan dengan membuka `index.html` atau melalui GitHub Pages.
